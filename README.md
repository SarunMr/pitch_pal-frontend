# PitchPal Frontend

PitchPal is an equity-based investment platform that connects entrepreneurs with investors.
This repository contains the frontend application built with Next.js, TypeScript, and Tailwind CSS.

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- shadcn/ui
- Bun

---

## Features

- Modern landing page
- Authentication UI
- Login & Register forms
- Form validation with Zod
- Responsive design
- Scalable folder architecture
- Role-based system planning
